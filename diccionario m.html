HTML Terms Dictionary

Tag

Tag: An element used to define the structure of a web page.

Element

Element: A part of an HTML document defined by tags.

Attribute

Attribute: Extra information added to an HTML element.

Heading

Heading: A title or subtitle used to organize content on a web page.

Paragraph

Paragraph: An HTML element used to display a block of text.

Link

Link: An element that connects a web page to another page or resource.

Image

Image: An element used to display a picture on a web page.

Table

Table: An HTML structure used to organize information in rows and columns.

Form

Form: An HTML element used to collect information from users.

Button

Button: An interactive element that allows users to perform an action.

Header

Header: A section that usually contains introductory content or navigation.

Footer

Footer: A section usually placed at the bottom of a web page.

Body

Body: The section that contains the visible content of an HTML page.

Title

Title: The name of a web page displayed in the browser tab.
