Diccionario de Terminos de Software

Actualizacion

Actualizacion: Proceso mediante el cual un software recibe correcciones, mejoras de seguridad o nuevas caracteristicas para mantener su rendimiento y compatibilidad.

Agil

Agil: Metodologia de desarrollo de software basada en la colaboracion, la flexibilidad y la entrega rapida de valor mediante iteraciones cortas.

Algoritmo

Algoritmo: Secuencia ordenada de pasos logicos y finitos disenada para resolver un problema o realizar una tarea especifica.

Atributo

Atributo: Propiedad adicional que se anade a una etiqueta HTML para modificar su comportamiento o apariencia, como "src", "href" o "alt".

Base de datos

Base de datos: Sistema organizado de almacenamiento de informacion que permite guardar, consultar y gestionar datos de forma estructurada.

Boton

Boton: Elemento interactivo que ejecuta una accion cuando el usuario hace clic sobre el, como enviar un formulario.

Saber mas

Codigo abierto

Codigo abierto: Modelo de desarrollo en el que el codigo fuente esta disponible publicamente para ser usado, modificado y distribuido libremente.

Compilacion

Compilacion: Proceso mediante el cual el codigo fuente se traduce a un lenguaje comprensible por la maquina, generando un archivo ejecutable.

Contenedor

Contenedor: Elemento que agrupa otros elementos dentro de una pagina web, permitiendo estructurar y organizar el contenido.

Saber mas

Control de versiones

Control de versiones: Sistema que permite registrar, administrar y restaurar los cambios realizados en un proyecto de software.

Cuerpo

Cuerpo: En HTML, es la seccion principal de la pagina web definida por la etiqueta <body>, donde se coloca el contenido visible.

Encabezado

Encabezado: Elementos HTML que representan titulos jerarquicos en una pagina (de h1 a h6) y ayudan a organizar el contenido.

Entrada

Entrada: Elemento de un formulario (input) que recibe informacion escrita por el usuario como texto o contrasenas.

Saber mas

Enlace

Enlace: Elemento de hipertexto que conecta una pagina con otra, permitiendo navegar entre documentos o sitios web.

Error

Error: Fallo en un programa que impide su correcta ejecucion o el resultado esperado.

Estilo

Estilo: Conjunto de reglas CSS que definen la apariencia visual de una pagina web.

Etiqueta

Etiqueta: Elemento HTML usado para estructurar el contenido de una pagina web, como titulos, parrafos o imagenes.

Formulario

Formulario: Area en una pagina web que permite al usuario ingresar datos mediante cuadros de texto, botones o menus.

Funcion

Funcion: Capacidad dentro de un software que le permite realizar una tarea especifica o mejorar un proceso existente.

Imagen

Imagen: Elemento grafico insertado en una pagina web mediante la etiqueta <img>.

Interfaz

Interfaz: Medio a traves del cual sistemas, programas o usuarios interactuan entre si.

Logica

Logica: Parte interna del sistema encargada de procesar informacion y ejecutar acciones segun reglas definidas.

Marco de trabajo

Marco de trabajo: Tambien llamado framework, estructura conceptual y tecnica que facilita el desarrollo de software.

Memoria

Memoria: Componente del sistema donde se almacena informacion temporal o permanentemente para uso de los programas.

Maquina virtual

Maquina virtual: Software que simula el funcionamiento de un computador fisico, permitiendo ejecutar sistemas operativos en un entorno aislado.

Nube

Nube: Modelo que permite acceder a recursos informaticos como almacenamiento, servidores o software a traves de internet.

Operaciones

Operaciones: Actividades tecnicas y administrativas para garantizar el correcto funcionamiento de sistemas y redes.

Parte visual

Parte visual: Interfaz grafica con la que interactua el usuario, incluyendo menus, botones e iconos.

Prueba unitaria

Prueba unitaria: Tecnica que evalua pequenas partes del codigo (funciones o metodos) para verificar su correcto funcionamiento.

Registro

Registro: Guardado de informacion sobre eventos y actividades del sistema en archivos de log.

Revision de codigo

Revision de codigo: Evaluacion del trabajo de otros desarrolladores para mejorar calidad y detectar errores.

Rendimiento

Rendimiento: Medida de eficiencia del sistema informatico en cuanto a velocidad y uso de recursos.

lenguaje tipado

lenguaje tipado:Un lenguaje de programacion es fuertemente tipado si no se permiten violaciones de los tipos de datos, es decir, dado el valor de una variable de un tipo concreto, no se puede usar como si fuera de otro tipo distinto a menos que se haga una conversion. No hay una unica definicion de este termino. Un lenguaje que se dice que no esta tipado se refiere a que no esta fuertemente tipado.

Div

Div: Elemento HTML que sirve para agrupar y organizar contenido dentro de una pagina web.

Parrafo

Parrafo: Elemento HTML que se utiliza para escribir bloques de texto mediante la etiqueta <p>.

Lista

Lista: Conjunto de elementos organizados en HTML, que puede ser ordenado o sin orden.

Tabla

Tabla: Elemento HTML que permite organizar informacion en filas y columnas.

Video

Video: Elemento HTML que permite insertar y reproducir videos directamente en una pagina web.

Audio

Audio: Elemento HTML que permite insertar y reproducir archivos de sonido en una pagina web.

HTML

HTML: Lenguaje de marcado utilizado para estructurar el contenido de las paginas web.

Head

Head: Seccion de un documento HTML que contiene informacion de configuracion y metadatos de la pagina.

Body

Body: Elemento HTML que contiene todo el contenido visible de una pagina web.

Enlace

Enlace: Elemento HTML que permite conectar una pagina o recurso con otro mediante la etiqueta <a>.

Meta

Meta: Etiqueta HTML que proporciona informacion sobre el documento, como su codificacion o configuracion.

Iframe

Iframe: Elemento HTML que permite insertar otra pagina o contenido web dentro de una pagina.
